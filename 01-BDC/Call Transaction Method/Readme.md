# BDC - Call Transaction Method

The Call Transaction Method is used to upload data into SAP by executing a transaction directly from an ABAP program using the CALL TRANSACTION statement.

Let's understand the implementation step by step with a practical example.

- Practical example
  Suppose you want to create multiple customer or material records in SAP using data from an Excel or text file.
  Instead of entering every record manually, you can automate the process using BDC.
